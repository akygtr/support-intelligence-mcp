# RAG Corpus

Source documents are not committed. They are PTC-copyrighted manuals,
freely downloadable but not redistributable.

Download these into this folder before running the indexing pipeline:

| File | Source |
|---|---|
| kepserverex-manual.pdf | PTC Kepware documentation portal, KEPServerEX server manual |
| modbus-serial-manual.pdf | PTC Kepware documentation portal, Modbus Serial driver |
| iot-gateway-manual.pdf | PTC Kepware documentation portal, IoT Gateway |
| secure-opc-ua-tunneling.pdf | PTC Kepware documentation portal |
| wireshark-opc-ua-diagnostics.pdf | PTC Kepware documentation portal |

The built index is committed, so retrieval can be evaluated without
re-downloading the sources.
